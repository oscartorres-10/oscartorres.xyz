# CV

Place the current CV at `public/Oscar_Torres_Frontend_Engineer.pdf`.

The stable URLs `https://oscartorres.xyz/cv` and
`https://oscartorres.xyz/resume` redirect to that PDF. The case variants
`/CV`, `/Resume`, and `/RESUME` are also supported as fallbacks for manually
typed URLs. To publish an updated version, replace the file with the same name,
commit the change, and deploy the site. The public URLs remain unchanged.
